# Caption Cadence Website

Website source for Caption Cadence — an independent caption suite for DaVinci Resolve Studio.

## Structure

- `index.html` — site entry point
- `styles/` — CSS
- `scripts/` — JavaScript
- `assets/images/` — screenshots, logos, and other image assets
- `assets/downloads/` — public downloads linked from the site

The custom-domain `CNAME` file will be added once the site domain is selected.
